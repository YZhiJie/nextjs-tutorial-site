全栈实验室 · 22 个沙箱 ​

每个实验对应一个可运行的 Next.js 16.4 沙箱。VitePress 站点提供实验说明与操作要点，交互式容器运行在原始 Next.js 应用中。

  • 缓存命中与按需失效 · 进阶 — 对比不缓存函数与 use cache 缓存函数的差异，并用 Server Action 配合 revalidateTag 让缓存按需失效。
  • 客户端交互：筛选与加购 · 入门 — 厘清服务端组件与客户端组件的边界：服务端提供内存商品数据，客户端组件负责加购计数与关键词、分类即时筛选。
  • Suspense 流式渲染 · 进阶 — 用独立 Suspense 边界观察 HTML 分片流式到达，并用路由级 loading.tsx 体验慢页面的骨架屏。
  • 复现并修复并发丢更新 · 进阶 — 快速重复提交下的 read-modify-write 竞态导致丢失更新。先用 Promise.all 并发提交复现计数错乱，再用一条 Promise 队列串行化写入修复。
  • 复现并修复鉴权绕过 · 进阶 — 鉴权只放在 proxy（边缘代理）的经典事故：页面有 302 拦截看似安全，curl 直连 API 却无需任何凭证拿到数据。先复现绕过，再把鉴权断言下沉到数据访问层。
  • 复现并修复缓存陈旧数据 · 进阶 — 写入后忘记失效缓存，页面读到陈旧数据。借助 tag 失效基础设施（createCached / expireTag）复现 STALE，再在写入后调用 expireTag 修复。
  • 复现并修复 hydration mismatch · 进阶 — 服务端预渲染与客户端首屏标记不一致引发的 React hydration mismatch。先复现「渲染期直接读时钟」导致的首屏不一致，再让首屏用稳定占位、挂载后写真实时间。
  • 复现并修复即时导航降级 · 进阶 — Instant Insights 报「导航不够即时」的典型根因：渲染被动态数据阻塞。先复现「等数据到位才输出」导致首字节拖到 250ms，再改成「外壳先行、数据区流式补齐」的分块渲染。
  • 复现并修复 after 链丢失 · 进阶 — 中间件里漏写 await next() 的连锁反应：执行顺序颠倒、耗时统计失真、错误逃逸成未捕获异常。先在洋葱链上复现这三种症状，再补回 await 串起主干。
  • 观测动态信号一票否决 · 进阶 — 以为是静态页（○），构建后却是 ƒ 且内容不更新？多半是渲染链里触达了 cookies()/headers()。先用探针观测「一票否决」全过程，再把会话值收进动态孤岛。
  • 你好，Next.js 16.4.3 · 入门 — 从零运行一个最小 App Router 项目：观察服务端渲染的时间、Link 客户端导航，以及服务端组件零 JavaScript 的含义。
  • 手写 Server Action 调用管线 · 进阶 — 不依赖 Next.js：用约百行代码实现 Server Action 的完整链路 —— Flight 序列化（$ 标签保住 undefined/Date）、action 注册表查找、参数反序列化执行、错误 digest 化与 Flight 行响应，配 5 个可运行校验用例。
  • 手写 tag 失效迷你缓存 · 进阶 — 不依赖任何框架：实现「先读缓存、未命中回源并登记」的 use cache 迷你版，以及 tag 反向索引驱动的 updateTag 失效传播，配 6 个可运行校验用例。
  • 手写 Flight 行协议序列化器 · 进阶 — RSC 的传输格式长什么样？手写 vnode → Flight 行的序列化器与客户端 rebuild：宿主标签直出、客户端组件编成 I 行 + "$<行号>" 引用、key 与嵌套结构完整往返，配 5 个可运行校验用例。
  • 手写 ISR 再生成调度（stale-while-revalidate） · 进阶 — 不依赖任何框架：实现「新鲜命中 / 过期先返回旧值 / 冷启动同步生成」三态调度与单飞去重，配 7 个可运行校验用例（含并发惊群）。
  • 手写中间件洋葱链 · 进阶 — 不依赖任何框架：用约 70 行 TypeScript 实现 Koa 式 compose —— 递归的 dispatch/next、异步回卷与短路，配 5 个可运行校验用例。
  • 手写迷你文件系统路由 · 进阶 — 不依赖任何框架：用 Node 内置模块实现「目录扫描 → 路由树 → URL matcher」三段管线，含动态段捕获与静态优先策略，配可运行校验脚本。
  • 搭建可观测管线：指标、钩子与面板 · 进阶 — 给迷你服务器接上 instrumentation 管线：register() 启动钩子初始化指标单例，环形缓冲记录每次请求的 TTFB，渲染耗时与缓存命中分开累计，最后由 /__metrics 面板暴露 p95 与命中率。骨架缺了两处关键记录调用，先复现再补全。
  • Route Handlers 与 proxy · 实战 — 编写返回 JSON 的 Route Handlers，并用 Next 16 的 proxy 为接口统一注入 X-Lab 响应头。
  • 嵌套路由与布局 · 进阶 — 用一个最小商城掌握嵌套布局、动态路由 await params、notFound 中文 404 边界与可选捕获所有段。
  • Server Actions 待办清单 · 实战 — 用 Server Actions、useActionState 与原生表单实现待办增删，禁用 JavaScript 后表单依然可以提交。
  • 样式与静态资源 · 实战 — 实践 next/font/google 自托管字体、next/image 远程图白名单、metadata 与深色 CSS 变量主题。
