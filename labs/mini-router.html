手写迷你文件系统路由 ​

难度：进阶 ｜ 默认端口：3000

不依赖任何框架：用 Node 内置模块实现「目录扫描 → 路由树 → URL matcher」三段管线，含动态段捕获与静态优先策略，配可运行校验脚本。

启动方式 ​

bash
npm install
node server.mjs
1
2

操作提示 ​

  • 步骤 1 先点「运行校验」，观察失败用例
  • 在左侧编辑 lib/router.mjs 补全 match()，再运行校验
  • 步骤 2 是参考答案：对照差异，理解静态段优先的打分策略
