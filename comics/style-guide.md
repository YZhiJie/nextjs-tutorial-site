# Next.js 漫画剧场 · 视觉与叙事规范

> 风格沿用 `frontend-advanced-guide/comics` 的「霓虹墨 Neon Ink」体系，内容改为 Next.js 16.3 教程的 14 章。

## 画布与栅格

- 画布 `viewBox="0 0 1200 840"`，深墨渐变 `#0b1220 → #101a33`。
- 2 × 2 四格，面板 `572 × 361`，坐标依次为 `(20,84)`、`(608,84)`、`(20,462)`、`(608,462)`。
- 页眉：EP 徽章 `#7C3AED` 92 × 36，标题渐变 26px，右侧系列名 13px，`y=62` 渐变分隔线。
- 页脚水印：`NEON INK · nextjs-tutorial · EP.NN`。

## 色板

| 用途 | 颜色 |
| --- | --- |
| 底色 | `#0b1220` / `#0e1730` / `#111a30` |
| 结构线 | `#223055` / `#1e2a44` |
| 霓虹强调 | 青 `#22d3ee`、紫 `#a78bfa` / `#7C3AED`、品红 `#f472b6`、橙 `#f97316`、绿 `#34d399`、黄 `#fbbf24` |

面板编号色固定：1 青、2 紫、3 品红、4 橙。底色占 60%，结构线 30%，霓虹强调不超过 10%。

## 角色

- **像素酱**：青色高马尾、紫卫衣，代表“动手验证”的读者视角。
- **标签君**：橙色刺猬头、蓝外套，负责抛出困境与常见误解。
- **码叔**：白发白须、圆框眼镜、浅灰大褂，负责揭秘、实证与结案。

## 四幕结构

1. **困境**：一个真实开发场景 + 一段错误或朴素写法。
2. **揭秘**：机制图（2–3 个流程块）或关键概念对照。
3. **实证**：可运行代码 / 配置 / 输出，给出“改前 → 改后”。
4. **结案**：⚠ 坑点清单 + 码叔总结。

每格固定：对话框两行（单行汉字不超过 17 字）+ 内容区 + 底部结论条。所有 `<text>` / `<tspan>` 必须显式写 `font-size`。

## 命名与配套

- 文件：`EP.NN-slug.svg` + `EP.NN-slug.md`，NN 与教程章号一致。
- 每话 MD 固定结构：标题、对应正文与实验、剧情回顾、逐格知识点、延伸实验、坑点清单、自测 3 题（含答案）。
- 生成：`node scripts/build-comics.mjs`；校验：`node scripts/check-comics.mjs`。

## 阅读器

- 单文件零依赖 `index.html`，运行时读取 `manifest.json`。
- 双模式：翻页（默认，一话一屏）/ 长卷（连续滚动）。
- 目录、话目网格（关键词 + 分册筛选）、讲解抽屉、`localStorage` 续读、键盘快捷键（←/→、M、G、Esc）。
- 进度键：`nextjs-comic-reader-progress-v1`。
